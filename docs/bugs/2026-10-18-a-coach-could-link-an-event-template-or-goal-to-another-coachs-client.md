# A coach could link an event, a template or a goal to another coach's client

**Closes when:** A live spec on the real API that tries the move for an event, a template and a goal and is refused, while a coach's own client, the coach's own personal record and a null client_id still work, plus a local verifier whose every deliberate break of the script fails.

Closed with that evidence on 2026-10-25; see `status_detail`. The same day the signed-out role (`anon`) lost every table, sequence and nine-function privilege it did not need (`scripts/harden-anon-access-2026-10-18.sql`, applied by Jake; a signed-out request to any of the 25 tables the app queries now answers HTTP 401), and the two trigger functions the Supabase Security Advisor flagged had their `search_path` pinned (`scripts/pin-trigger-search-path-2026-10-25.sql`).

# The invite-client function loads an unpinned library and ignores failed writes

**Closes when:** The deployed invite-client pins supabase-js to an exact version, refuses an email that already has an account (as invite-solo-user does) without saying which, checks the result of the profile upsert and the client link (with .is('user_id', null) on the link) and says so when either fails (so the invite is not reported as a success), and answers an unauthorised call with 401 or 403; the repo copy is byte-identical to the deployed one.

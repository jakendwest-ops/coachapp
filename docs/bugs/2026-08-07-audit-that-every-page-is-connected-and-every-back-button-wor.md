# audit that every page is connected and every Back button works

**NEW — audit that every page is connected and every Back button works.** Jake, live 2026-08-07: *"check that all of the pages are connected (specifically the back buttons work on all pages)."* A whole-app navigation audit, not a single bug: every Back/return affordance on every surface, for all three roles (coach, client, solo).

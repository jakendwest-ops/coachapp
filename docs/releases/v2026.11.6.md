## What shipped

- **Adding an exercise is quicker.** The exercise list opens at once after the first time, instead of re-reading the whole library
  every time (it was read in 200-row pages, one after another, for every exercise added).
- **A new Add exercise form** for weight & reps and unilateral:
  - Straight sets | Top set + back-offs at the top.
  - Sets and Reps on one row, Effort and Rest on the next, each with Fixed / Range. Rest can be typed or stepped 30 s at a time.
  - A new exercise starts from the previous one's sets, reps, effort and rest, and says so.
  - "Customise each set" is a row of set tiles; tap one to change it.
  - The rarely used extras are More options chips: Type, Load, Tempo, Countdown, Notes, Last set AMRAP, Unilateral, Bodyweight.
  - The Add buttons stay pinned at the bottom on a phone. On desktop, Enter adds and goes on to the next exercise.
- **A range can no longer be saved upside down** (12–8 reps, 2:00–0:30 rest): the form keeps the order, and the save enforces it.
- **"% of last session's e1RM":** a percentage worked out from that exercise's best working set last time. It uses the same number
  My Progress shows, needs no saved 1RM, and shows a blank with a note when there is no history.
- **On Straight sets, "% of today's top set" or "% of today's e1RM" means set 1 sets the weight** (Jake, 2026-11-15): set 1 is
  worked up to with no %, and the percentage applies from set 2.

Technical:
- `js/app-workouts.js`:
  - `_exerciseLibCache` (keyed owner + view, a generation count against stale reads, dropped on every library write and on sign-out).
  - `_sfRender` and the `sf*` handlers (same input ids, same `sets_json`).
  - `_rangeInOrder` in `_cleanTemplateSets`, and `_sfSet1Shape`.
  - `_tsPropagate` copies the group's % from set 2 when set 1 sets the weight.
- `js/app-core.js`: `_isLiveBasis`, `lastBest` labels.
- `js/app-runner.js`:
  - `_bestE1RMOfSets` uses `_sessionBestE1RM`.
  - `_set1IsReference`.
  - `lastSessionDone`, so the "can't work it out" note never flashes.
- `js/app-programs.js`: `_isLiveBasis` in the 1RM needs, the wave and the held count.
- `js/app-progress.js`: drops the picker cache on sign-out.
- `css/main.css`: `.sf-*`.

## Scope

Jake kept walking the live v2026.09.4 build and flagged issues as he found them. Five fixes ship
here — all self-contained, no deferrals this round.

**In:**
- A builder day-slot's detail panel opens directly under the day you tapped, not at the bottom of
  the whole week.
- The runner's SET/KG/REPS header lines up with its columns again.
- Long exercise names in the runner clamp to 2 lines instead of wrapping freely.
- The runner's exercise-jump strip is numbered, gapped, scrollable squares instead of a thin
  touching bar.
- The set editor gained a small per-row "copy set above" control, and the exercise-row list in the
  template builder gained a direct Remove button next to Edit.

## What shipped

**The builder detail panel opens where you tapped.** `renderPhaseWeekGrid`'s open-slot preview used
to render once, after the entire `.pwk-days` grid — so on mobile (where days stack vertically) it
always landed at the bottom of the week regardless of which day you opened. It's now emitted as a
sibling right after the owning `.pwk-day`. Desktop's ≥768px full-width-below-the-grid placement
(shipped 2026-09-09) is unchanged: a CSS `order`/`grid-column:1/-1` rule keeps the one open panel on
its own row after all seven days, however it's positioned in the DOM.

**The runner's column headers line up.** The delete (×) button on a set row only renders when an
exercise has more than one set, but the header never reserved space for it — so on any multi-set
exercise, KG and REPS sat narrower than their labels. The header now reserves the same 40px whenever
the delete button will actually render.

**Exercise names clamp to 2 lines.** The runner's exercise title used to wrap freely; long names
could run to three or more lines. Clamped with `line-clamp`/`-webkit-line-clamp`.

**The exercise-jump strip is numbered squares.** The old thin 8px bar's segments got thinner (and
easier to misclick) the more exercises a workout had — worst exactly when precision mattered most.
Replaced with fixed 40×40 numbered squares, gapped, that scroll rather than shrink as exercise count
grows.

**Set editor: "copy set above."** Editing Set 1 used to mean retyping the same change into every
other set by hand. A small unlabelled "↑" beside each "Set N" label (Set 2 onward — deliberately not
a labelled pill in the AMRAP/BW/× row, which was stripped for being clutter on 2026-08-02/09-06)
syncs that set to match the one directly above it.

**Remove button on the exercise-row list.** Removing an exercise from a workout used to require
opening its Edit modal first. A "Remove" button now sits directly on the list row, next to Edit. That
modal-only path had no confirmation and stays that way (unmodified, out of scope); the new direct
path is one tap closer to a delete with no "enter edit mode" step first, so it gets a `confirmDialog`
guard the modal's own button doesn't have.

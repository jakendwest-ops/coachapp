## What shipped

- **Rest timer:** ticking a set no longer pushes the set rows down. The countdown is the REST box in the prescription strip, and a tap on it skips. The strip always has a REST box, so it never grows.
- **Fill from last time:** a button above the sets turns the grey numbers into real values in one tap. It never changes a typed box, a ticked set, effort, a range, or a top-set exercise, and every set is still ticked by hand. Once used up it stays, greyed out, so the rows never move.
- **Copy-down:** ticking a set fills the next set when that set is empty, unticked and prescribes the same. Effort is never carried; back-offs on a top-set exercise never.

Technical: `js/app-runner.js` (v135): `_renderPrescriptionLine` live REST cell; `_copyDownFrom`, `_fillValues`, `_pendingFills`, `fillFromLastTime`, the `#wr-fill-last` button. Values stay canonical kg/cm. Specs: `runner-rest-slot-2026-11-13`, `runner-fill-copy-down-2026-11-14`; `runner-layout-2026-09-28`, `runner-exercise-nav-2026-09-28` and `runner.spec.js` updated for the deliberate changes.

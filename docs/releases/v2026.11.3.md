## What shipped

Plain English first.

- **Logging:** the rest target reads "3:00", not "3:00–0:00". One PR trophy per exercise, and none on a first-ever log. With no saved 1RM, the question comes on a first log and then only on a new heaviest set. Solo sessions say Notes.
- **Building:** Enter picks or creates in the exercise picker. A new lift opens at 3 sets and Add another keeps going. A solo plan is made with its first block and starts next Monday unless a plan is already running. Saving a workout confirms it.
- **Words:** Template is now Workout, Training plan is now Plan and Phase is now Block on every screen. Solo users see Start this plan; the coach's tab is Saved workouts. Database and code names are unchanged.
- **Plans that progress:** Add periodization has a "+kg" option beside % of 1RM and RPE, one amount per block, with a preview and an optional deload week.
- **Goals that track:** a weight goal can follow the newest weigh-in or a lift's heaviest set since the goal began, on the Goals list, the goal page and Today. Finishing a goal saves the number reached.
- **The story of a block:** Performance opens on "Stronger on X of Y lifts" over 6 weeks. Records adds "Logged best" when training has passed a saved 1RM, without overwriting it. Bodyweight shows kg per week and a projected date, and a goal that follows body weight is the one target on both weight pages. Today offers a missed session with Start or Skip, unless today has its own session. Train links to the full session history.
- **One look:** Add block is a sheet, Save is the one primary button while changes are unsaved, text is at least 11px, and close buttons and toggles are 44px. An unfinished workout is offered on Today and Train. The month calendar marks done and missed days by the week strip's rule.
- **Plan page:** one button look, ⋯ menus for occasional actions, week tabs that fit a phone, and Close instead of ✕ on its sheets.
- **Week navigation:** ‹ › on Today's week card and a week at a time on the Sets per week bars.
- **Sessions:** a Change column for weight, reps, time and RPE, and one layout for first-time sessions.
- **Fixed along the way:** the Blocks page could lose newer finished runs past the API's 200-row cap, the resume dialog counted one tick as two sets, opening a session with no earlier one no longer causes a 406, and a block tapped in the plan bar while the sessions were still loading ended up off screen.

Technical: `_liftStory`, `_sessionBestE1RM`, `_showLoggedBests`, `_weightTrend`, `_linkedBodyweightGoal`, `_weightTargets` (`js/app-progress.js`); `_dashMissedHtml`, `_dashSkipMissed`, `_dashWeekRange`, `_dashStepWeek` (`js/app-dashboard.js`); `_setChange`, `_sessionSoloHtml`; basis `kg` and `stepKg` in the existing `periodization_config`; `goals.linked_metric` and `goals.linked_exercise_id`.

## Known issues carried into this release

- A numbered goal step can untick if body weight rebounds. Acceptable: the goal shows the true current number.
- A rep record at the same weight does not prompt for a 1RM when none is saved, by design.
- A timed hold's trophy goes to the first set. Acceptable: cosmetic.
- Records' "Logged best" reads the whole history on each paint. Acceptable: bounded, and the same read as the Performance page.
- Skip on a missed session is remembered on that device only.
- "One history list" is a link from Train to the full list. Train keeps its newest five.
- The calendar's small 8px workout names stay.
- A block tapped in the plan bar during loading scrolls again when the sessions arrive, even if you have scrolled away since. If one plan is rendered twice at once, a tap in that gap gets no second scroll. Acceptable: both are rare and only affect scroll position.
- Two weak negative assertions remain in `tests/per-program-2026-08-16.spec.js:172` and `tests/performance-blocks-2026-11-01.spec.js:84`.
- `pb-consolidation-2026-08-17.spec.js`'s SOLO write path is timing-sensitive in the test (a fixed sleep).
- The Supabase API log check for these flows and the Auth redirect URL check were not run (they need the dashboard).
- Supabase log ingestion is over the Free plan's limit until the billing cycle resets on 19 Nov. It cannot be reduced, and whether it alone brings restrictions is not known.
- GDPR consent capture stays deferred by Jake ([row](../bugs/2026-08-11-gdpr-no-consent-capture-and-no-privacy-policy.md)).

# Decisions of 2026-10-28, archived verbatim

Moved out of `docs/decisions.md` on 2026-10-28 to keep the top-level docs inside the `os-lint` docs budget. Read for detail; `decisions.md` carries the one-line pointer.

**2026-10-28 — The exercise builder is rebuilt around groups, and "% of" gets a third choice.** Jake: the workout page and the Set targets section were hard to use, a back-off set needed a clear "% of the top set's weight, or % of the e1RM" choice, and the "↑" copy button "only makes sense to me because I know what it means". Decided: (1) sets that match are edited as ONE group ("Straight sets" / "Top set + back-offs", a count stepper, one row of fields) and "Customise each set" opens the old per-set cards, which also open on their own when the sets already differ so a difference is never hidden; the copy button now reads "Same as set N". (2) `intensityBasis` gains `'topSetWeight'` (% of the weight lifted on the top set). The old `'topSet'` keeps meaning today's *estimated 1RM*, so no saved template changes meaning; the editor relabels them "Last saved 1RM" / "Today's estimated 1RM" / "Today's top set weight", with a worked example the coach can type into. New back-off sets start on the top set weight, because it needs no effort or saved 1RM. (3) Jake's 2026-08-14 rule stands: AMRAP is a visible switch on the last set, never hidden by grouping; other exercise types keep the per-set cards. (4) The page's exercise cards are one summary each (the whole card edits), Remove moved into the editor with an 8-second Undo on the page, and moving exercises is a Reorder mode. Rejected: a new `intensityBasis` value for the old meaning (would have rewritten saved templates), and silently flattening differing sets into the grouped view.

**2026-10-28 — Beeps stay, and the sound engine is rebuilt after the page is hidden.** Jake's gym use showed the beeps die for good once Safari is left (measured twice on his iPhone: the engine's clock stops while it still says "running" or "interrupted"; `resume()` does nothing, a new engine works). Voices never had this (speech does not use that engine) but pause Spotify on every cue, the original bug; Jake chose beeps ("fix using beeps"). `_unlockAudio` replaces a stale, closed, interrupted or clock-frozen engine at the next tap, a tap anywhere in the runner counts, and the rest timer never rebuilds. Known gap: a rest already running when he switches away stays silent until his first touch of the screen; a "Tap to turn beeps back on" prompt waits for his go-ahead.
